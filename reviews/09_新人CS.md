# 09_新人CS視点レビュー

レビュアー想定: 入社初日の新人CS。CS業務未経験、SaaS用語にも不慣れ。今日初めてこのポータルを開いた。

対象ブランチ: `main` / `neo-cs-v2/`
レビュー日: 2026-05-03

---

## 総評

率直に言うと、**新人が一人で立ち上がるのは無理**な作りです。
画面は綺麗で情報量も豊富ですが、それは「業務を知っている人」が見れば便利、というレベル。初日の自分が開くと、目に入る単語の半分以上が分かりません。

具体的には:

- トップ (`app/page.tsx`) を開くと「MRR」「At-Risk」「Health: Red + Yellow」「更新ファネル」「研修別サマリー」が並んでいるが、**一つも説明がない**
- ヘルプ (`app/help/page.tsx`) は「箱だけ」あって中身が空。カテゴリカードは全部 `href="#"` でクリックしても動かない
- ツールチップ (`title=` 属性すら) は、TopNav・ダッシュボード・オンボーディング画面いずれにも**ほぼ存在しない**
- 用語集・グロッサリー・初回オンボーディングツアーに該当するファイルが**コードベース上に見当たらない** (`components/` 配下に `Tooltip` `Glossary` `Empty` `Onboard*Tour` 等は存在しない)
- 「新人がまず最初に開く画面」「最初に読むべきページ」への導線が、ホームにもユーザーメニューにも無い

つまり**「何を、何のために、どう操作すれば良いか」が画面上から学べない**。隣の先輩に聞かないと一歩も進めません。これはSaaSプロダクトとしてはまだしも、**社内ポータル**としては致命的です（社内ポータルは退職・異動で常に新人が入る前提のはず）。

---

## 致命的問題

### 1. ヘルプページが「リンク先ゼロ」のハリボテ

`app/help/page.tsx`:

- L74-95 カテゴリカード6種類（使い方ガイド/FAQ/リリースノート/動画チュートリアル/ショートカット/お問い合わせ）すべて `href="#"`。**一つもリンクが繋がっていない**
- L62 「よく検索されるキーワード」のチップも全部 `href="#"`
- L51-57 検索バーは `<input>` と `<button>` だけで、`onChange`/`onSubmit` も無い → **検索しても何も起きない**
- L114 「FAQ一覧をすべて見る →」も `href="#"`
- L186 「ステータスページを開く →」も `href="#"`
- L20-26 FAQ本体はわずか**5問**。「ヘルススコアはどう算出されますか?」のような最重要質問が1行で済まされており（L21）、新人が見ても「加重平均」「重み付け」がさらに分からない

新人視点での実害: 「ヘルプを開けばわかる」という最後の砦が**完全に機能不全**。これに気づいた瞬間、ポータルへの信頼が崩壊します。

### 2. ダッシュボード上の専門用語に説明が一切ない

`app/page.tsx`:

- L51-74 KPIカード4枚:
  - L53 「取引中企業」→ 「契約 N件（継続型）」とあるが、**「継続型」とは？** スポット型と何が違う？
  - L57 「アクティブ参加者」→ 「受講中の総数」だけ。研修受講者なのか、ログインしている人数なのか不明
  - L64 「MRR」→ 略語のまま。`sub` に「売上規模 N円/月」とあり、ますます **MRR と売上規模の違い** が分からない
  - L69 「At-Risk企業」→ いきなり英語。`sub` の「更新予定 N件（90日内）」も関係性が不明
- L80 `<HealthSection />`、L81 `<RenewalFunnel />` が並ぶが、**ヘルス／ファネルの定義がページ上に無い**
- L150 「🚨 要対応企業（Health: Red + Yellow）」→ 信号機の色だけで、**Red/Yellow/Green の閾値や判定ロジックの説明なし**
- L163 表ヘッダ「🤖 AI推奨」→ AI が何を根拠に推奨しているか、信頼してよいかの注釈ゼロ
- L186 表セル `a.suggestedAction` がそのまま表示されるが、**新人がこれを実行する手順**（誰に確認、どのテンプレを使う等）が無い
- L161 「最終接点」→ 「接点」は CS用語。新人には「最後にメールしてから？電話？面談？全部？」が不明

### 3. 「新人オンボーディング」を支援するUIがゼロ

- `app/onboarding/` は **顧客側のオンボーディング**（契約開始までのチェックリスト）であり、**自社の新人スタッフ向けのオンボーディング画面ではない**。L277「契約単位のチェックリスト」とあるが、新人は最初これを自分のオンボと誤読する恐れあり（用語の衝突）
- ホーム `app/page.tsx` に「初めての方へ」「ガイドツアー」「クイックスタート」のバナーや CTA が**一切ない**
- ユーザーメニュー (`components/TopNav.tsx` L306-358) にも「ヘルプ」リンクはあるが「初心者ガイド」「業務マニュアル」「用語集」へのショートカットは**無い**
- 全画面を grep してもツアーライブラリ（react-joyride 等）や `data-tour` 属性、初回モーダル等の痕跡なし

## 重要な懸念

### 4. ナビゲーションのラベルが略しすぎ

`components/TopNav.tsx` L7-18:

```
ダッシュボード / マイページ / 受信箱 / 企業 / アンケート / オンボ / 週次 / 更新 / 出席 / 設定
```

- 「オンボ」← **何のオンボ？** 自分の？顧客の？業界外の人にはまず通じない
- 「週次」「更新」← 名詞単独で目的語が無い。「**週次レビュー**」「**契約更新**」と書くべき
- 「出席」← 何の出席（自分の勤怠？参加者の研修出席？）か曖昧
- ホバー時の `title` 属性も無いため、マウスオーバーでの補足説明も得られない

### 5. エンプティステートが「投げっぱなし」

- `app/onboarding/page.tsx` L420 「該当する契約はありません」だけ。**フィルタを外すボタン**も**新規追加への導線**も無い
- L458 「完了済の契約はありません」も同様
- ヘルプ FAQ L102-112 は0件時の表示が無いが、そもそもハードコード5件なのでそれは表示されない（が、もし将来動的になれば破綻する）

新人は「自分の操作が悪いのか、データがゼロなのか」判断できません。

### 6. ミスのリカバリ手段が不明

- ヘルプ L25 「退職した担当者のアカウントはどうなりますか?」→ 「無効化すると引き継ぎ先に自動アサイン」とあるが、**Undo/取消方法は書かれていない**
- ヘルプ FAQ にそもそも「**操作を間違えたとき**」「**誤って削除したとき**」「**メールを誤送信したとき**」の項目が無い
- 「お問い合わせ」フォーム (L120-155) はあるが、SLA（何時間以内に返信が来る？）が L162 「平日10:00-18:00」しか書かれておらず、緊急時にどうすればいいか不明

### 7. 「業務の型・正解」を学べない

- 「要対応企業」表 (L168-196) で `a.suggestedAction` が AI推奨として出るが、**「なぜそれが正解なのか」**「**過去の成功事例**」「**テンプレート文面**」へのリンクが無い
- ヘルプの「使い方ガイド」(L12) は説明文のみで本体ページが無いため、**業務フロー（顧客との初回MTG → 週次 → 更新）の全体像**を学ぶ場所がどこにも無い
- 週次レビューがどんな項目をどんな粒度で書くべきか、Good/More/Next の定義（直近のコミット履歴 `678e39d` で追加された）の説明も画面内に無い

### 8. 自己解決導線の弱さ

新人が「自分で調べてから聞く」を実践したくても:

- 検索が動かない（前述 L51-57）
- カテゴリリンクも全滅（前述）
- ツールチップも無い
- グロッサリー（用語集）が無い

→ **すべての疑問が「先輩に質問」に直結**。質問する前にプロダクト内で30秒調べる、ができません。

## 評価できる点

- TopNav (`components/TopNav.tsx`) の通知ドロップダウンはカテゴリ色分けされており、**何が起きたか**は直感的（L105-111）。新人でも「アラート色＝赤＝重要」は分かる
- ユーザーメニューのミニKPI (L291-304「担当社/本日タスク/未提出週次」) は**自分が今何をすべきか**が一目で分かる、良い試み
- `app/onboarding/page.tsx` のKPIカード (L324-349) は `sub` に「要即対応」「直近でオンボ仕上げ」など**動詞で次のアクション**が示されており、ダッシュボードのKPIより親切
- ヘルプの「ステータス」枠 (L180-189) で「全システム正常稼働中」が見える設計は◎（実装は静的だが思想は良い）
- 緊急連絡先と Slack `#cs-support` がヘルプ画面に明示 (L167-176) されている
- オンボーディング画面のフィルタ・表示切替 (`app/onboarding/page.tsx` L383-402) は3モード（カード/カテゴリ/項目）あり、新人は自分の見やすい粒度を選べる

## 改善提案

優先度順:

### P0（即対応）

1. **用語ツールチップ コンポーネントを新設**（例: `components/Term.tsx`）し、`MRR` `At-Risk` `Health` `ファネル` `継続型/スポット型` `接点` 等を初出時に説明付きでラップ
2. **ヘルプの `href="#"` をすべて実リンクに**。最低でも「使い方ガイド」「FAQ一覧」「用語集」の3つは静的ページで実装
3. **ヘルプ検索バーに最低限のクライアント絞り込み**（FAQ配列内検索）を実装。動かない検索はゼロより悪い
4. **ホーム上部に「はじめての方はこちら →」バナー**を出し、クリックで `app/help/getting-started` 等へ
5. **TopNav ラベルを正式名称に**: 「オンボ」→「オンボーディング（顧客）」、「週次」→「週次レビュー」、「更新」→「契約更新」、「出席」→「研修出席」

### P1（早めに）

6. **グロッサリー画面**を新設し、業界用語＋社内用語をアルファベット順／50音順で一覧化
7. **要対応企業表の AI推奨に「なぜ？」リンク**を付け、判定根拠とテンプレート文面を表示
8. **エンプティステートに「フィルタを外す」「新規追加」CTAを必ず添える**（`app/onboarding/page.tsx` L420 ほか）
9. **ヘルススコアの計算式を画面上に常設**（HealthSection の `i` ボタンでモーダル表示など）
10. **ミス時のリカバリFAQ**を最低10問追加（誤送信／誤削除／間違ったタグ／担当の付け間違い ほか）

### P2（じっくり）

11. **初回ログイン時のガイドツアー**（react-joyride 等）でホーム → 企業 → 週次 → ヘルプ の順に5ステップでハイライト
12. **「業務の型」ページ**: 顧客ライフサイクル（受注→オンボ→運用→更新）を1枚の図にし、各フェーズで使う画面と典型タスクをリンク
13. **質問フォーム送信前に類似FAQをサジェスト**（「同じ質問が3件あります」表示で自己解決を促す）
14. **SLA明記**: お問い合わせ画面に「初回返信目安: 営業時間内2時間以内」等の期待値を書く
15. **ロールベースのホーム**: Adminと現場CSと新人で初期表示を出し分け、新人は「学習チェックリスト」が前面に出るように

## 一言まとめ

**「綺麗な道具箱だけど、取扱説明書が同梱されていない」**。
画面の作り込みは熱量があるのに、そこに書かれた言葉を理解する手段がプロダクト内に存在しないため、新人にとっては優しくありません。ヘルプの中身を実装し、用語ツールチップを足し、ナビ名を正式名称にする。この3点だけで新人の立ち上がりは劇的に改善するはずです。
