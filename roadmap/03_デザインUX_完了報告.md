### 2. デザイントークン一本化案

#### 2.1 設計方針
- **意味論的トークン (semantic) を前面に**: `success` / `warning` / `danger` / `info` / `neutral` / `accent`。実装値は `brand` / `product` / Tailwindパレットに `tailwind.config.ts` 内で参照リンクし、コード側は意味語のみを使う。
- **raw hex を `tailwind.config.ts` の外で使用禁止**: ESLintルール `no-restricted-syntax` で `style={{ background: "#..." }}` と `text-[#...]` を警告対象に。
- **カードは `surface` 一本**: `liquid-card` 廃止、`liquid-surface` を `surface` にリネーム。すりガラス表現は装飾レイヤとして例外的にのみ使用。
- **角丸ルール**: `sm` (4) / `md` (8 = 旧 `rounded-lg`) / `lg` (12 = 旧 `rounded-xl`) / `xl` (16 = 旧 `rounded-2xl`) / `surface` (20 = 旧 `liquid` の 1.25rem) / `pill` (full)。`surface` 系コンテナは `surface`、内部要素は `md`、Pill/Chipは `pill`。

### 4. 過小フォント (10〜11px) 引き上げ対応リスト

- 通常テキスト・ラベル・補助説明 → `text-caption` (12px) を最小ライン
- 表のセル内・操作可能な要素 → `text-body` (14px) を最小
- KPI数値 → `text-metric` (28px) または `text-h2` (20px)

### 5. `focus:outline-none` 29箇所の代替設計

#### 5.1 統一フォーカススタイル (新規ユーティリティ)

```css
@layer utilities {
  .focus-ring {
    @apply focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-focus focus-visible:ring-offset-2 focus-visible:ring-offset-white;
  }
  .focus-ring-inset {
    @apply focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-inset focus-visible:ring-focus;
```

### ストリーム02 への申し送り

**新画面を書くときに使うもの**:
- 色: `bg-success-500` / `text-danger-700` / `border-info-100` 等 (semantic) または `bg-brand-blue` / `bg-product-academia` (ブランド/研修色)
- 文字サイズ: `text-caption` (12px補助) / `text-body` (14px本文) / `text-h4`〜`text-h1` / `text-metric`
- カード: `<div className="surface p-4">…</div>` (旧 `liquid-surface` の代替)
- 角丸: `rounded-md` (8px) / `rounded-lg` (12px) / `rounded-surface` (20px) / `rounded-pill`
- 影: `shadow-card` / `shadow-cardHover`
- フォーカス: 全てのインタラクティブ要素に `focus-ring` を付与 (テーブルセル等は `focus-ring-inset`)
- フォーム: `<label htmlFor={id}>` + `<input id={id}>` を必ず結ぶ
- ステータス: 色だけで意味を持たせない。アイコン + テキストを併記

**禁止事項 (lint warn)**:
- `className` に `[#xxxxxx]` を直書き
- `text-[10px]` / `text-[11px]` / `text-[9px]` / `text-[12px]`
- `focus:outline-none` 単独 (`focus-ring` か `focus-ring-inset` を併用)
